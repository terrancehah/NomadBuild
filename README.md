# NomadBuild

My attempt at promoting my website building service through outreach (like a one-man telemarketing operation). This project acts as a template for future client work as I transition to remote freelance.

---

## The Story

I always ask myself: _what if I could make a living from anywhere in the world?_

Just a laptop, and the willingness to promote my website building service through outreach.

This repo is the foundation of that experiment. So I built a reusable template — a full multi-page business website that can be re-skinned, rewritten, and redeployed for any small business in just a matter of days. The current version was shaped around a real-world client engagement, but the pillars of the site are designed to be swapped out entirely: brand colours, copy, images, page structure — everything is modular and clearly marked for quick customisation.

My goal isn't just to build one website. It's to build a repeatable workflow where each new project gets faster, cleaner, and more refined than the last.

## What's Inside

A production-ready, 5-page business website with everything a small business needs to look professional online:

**Home** — hero banner, value propositions with real photography, service highlights, latest news, testimonial carousel, and a strong call-to-action section. Designed to convert visitors into enquiries.

**About** — brand story, mission and vision, core values, full team showcase with alternating layout and animated reveals, and a stats section for social proof.

**Courses / Services** — detailed service listings with icons, feature breakdowns, and individual CTA buttons. Structured as a filterable card grid.

**Announcements** — news feed in a clean card layout with category tags and date stamps. Works as a lightweight blog alternative.

**Contact** — contact form with WhatsApp integration (form data gets pre-filled into a WhatsApp message), embedded map placeholder, operating hours, and all contact channels.

Every section uses scroll-triggered fade animations, and the entire site supports light/dark mode theming out of the box.

## Tech Stack

This is what I work with, and what every project built from this template runs on:

| Layer             | Technology                                                     |
| ----------------- | -------------------------------------------------------------- |
| **Framework**     | Next.js 15 (App Router)                                        |
| **Language**      | TypeScript                                                     |
| **Styling**       | Tailwind CSS 3                                                 |
| **UI Components** | Custom-built (no component library dependency)                 |
| **Icons**         | Lucide React                                                   |
| **Carousel**      | Embla Carousel                                                 |
| **Theming**       | next-themes (class-based dark mode)                            |
| **Fonts**         | Google Fonts via next/font (Noto Sans SC, ZCOOL KuaiLe, Anton) |
| **Deployment**    | Vercel                                                         |

Everything is typed, component-driven, and built with the Next.js App Router architecture. No CMS, no database — just fast static pages that score well on Lighthouse and load instantly.

## Where This Is Going

Each new client project will fork from this template, and lessons learned will be folded back in. The roadmap is less about features and more about refining the workflow: faster turnarounds, better defaults, and a growing portfolio of shipped sites that prove the concept works.

If you're a small business owner and you're reading this — feel free to reach out if you need a website!
